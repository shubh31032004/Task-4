# Production-Shaped Deployment

## Overview

This project demonstrates a production-ready deployment architecture for a web application on AWS.

## Components

- CloudFront CDN
- Application Load Balancer
- EC2 Web Servers
- RDS MySQL Database
- S3 Backup Storage
- CloudWatch Monitoring
- SNS Alerts

## Infrastructure as Code

Terraform templates are provided in the terraform directory.

## Monitoring and Alerts

CloudWatch monitors system health and sends alerts through SNS.

## Backup Strategy

- Daily database snapshots
- S3 versioned backups
- Disaster recovery plan included

## Runbooks

Runbooks cover:

1. Web server failure
2. Database failure
